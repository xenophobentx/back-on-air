Counts only: no names, no addresses. A sign-in's country is looked up from its address in an offline database on the server and only the day's totals per country are kept; the address is not stored. The server never receives a Steam account name or SteamID. "Unique players" are counted per UTC day, so a week or month adds days up (player-days), it is not a count of different people.

Race counts come from a heuristic (the host makes no server call while a race runs). Until a live test confirms it the server runs without it and those numbers show "–" with a note.
