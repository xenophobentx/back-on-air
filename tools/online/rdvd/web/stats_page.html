Back on Air is an unofficial patch for the Steam release of Split/Second. We run this server for the game's own online play. It signs players in and lists games; the races themselves run between the players' computers. The numbers here are counts only. We do not show or keep player names, game names or addresses. The server never receives a Steam account name or SteamID. This is a fan project, not affiliated with or endorsed by Disney or Black Rock Studio. Font: Barlow Condensed (SIL Open Font License).
